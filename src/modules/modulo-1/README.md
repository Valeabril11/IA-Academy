# Módulo 1 — Fuentes, cobertura y alcance

## Fuentes originales utilizadas
- `clase_m1_c1_1.pptx`: introducción, herramientas, capacidades, dinámica y TP.
- `class_m1_c1_2.pptx`: historia, Test de Turing, jerarquía IA/ML/DL/LLM, tipos de aprendizaje.
- `class_m1_c2_1.pptx`: UNESCO, ISO 27001/42001, casos y Python básico.
- `class_m1_c2_2.pptx`: sesgos de datos, modelo, proxy e interpretación, mitigación y Coded Bias.
- `class_m1_c3_1.pptx`: Python, Iris, clasificación y regresión.
- `class_m1_c3_2.pptx`: métricas y caso antifraude.
- `class_m1_c4_1.pptx`: pipeline de clasificación end-to-end.
- `class_m1_c4_2.pptx`: clustering end-to-end y K-means.
- `M1 C1 - Introducción a la IA y Fundamentos de Machine Learning.pdf`: fundamentos, hitos, tipos de IA y aplicaciones.

## Organización
Ocho lecciones con IDs estables `m1-l1` a `m1-l8`. Las cuatro primeras preservan sus IDs originales. Cada lección contiene objetivos, teoría, ejemplo, cuatro preguntas autocorregibles con justificación y cinco o más flashcards.

## Material complementario
Los apartados marcados «ampliación didáctica», el código ilustrativo, los ejemplos numéricos, las fórmulas desarrolladas, las sugerencias de operación y las métricas complementarias son explicaciones agregadas para enseñar el contenido, no citas literales de las presentaciones.

## Pendientes y límites
- No se incluyeron archivos fuente de los notebooks de Colab ni la consigna del TP obligatorio N.º 1. Por tanto, no se afirma haber reproducido sus ejercicios exactos.
- El formato de `sections.body` es texto plano según `src/types/course.ts`; los ejemplos de código se muestran como texto en el bloque de ejemplo existente.
- El marcado de completado sigue siendo manual; los quizzes autocorrigen respuestas pero no certifican aprobación ni alteran el progreso.
- Las afirmaciones históricas, estadísticas o simplificaciones de las diapositivas se contextualizaron; no se validaron externamente.
- No se modificaron otros módulos, contratos, rutas ni componentes.
